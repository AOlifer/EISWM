EISWM v1

Назначение
Управление MP3-файлами в каталоге приветствия:
/data/user_de/0/com.android.launcher3/files/welcome/message

Изменения EISWM v1
- Справочная информация сделана компактной горизонтальной панелью, чтобы не занимать высоту экрана.
- Верхняя кнопка «Обновить» перенесена в нижнюю панель.
- Нижняя панель разделена на две части:
  слева — «Вверх», «Память устройства», «Внешние накопители», «Обновить»;
  справа — статус воспроизведения и «Стоп».
- «Память устройства» возвращает из внешнего накопителя во внутреннюю память.
- При выборе внутренней памяти корнем навигации является только /storage/emulated/0.
- При выборе внешнего накопителя навигация ограничена корнем выбранного накопителя.
- Слева показываются каталоги и MP3-файлы.

Иконка приложения
Для Android 9 достаточно обычной PNG-иконки. Рекомендуемый комплект:
- mipmap-mdpi/ic_launcher.png       48x48 px
- mipmap-hdpi/ic_launcher.png       72x72 px
- mipmap-xhdpi/ic_launcher.png      96x96 px
- mipmap-xxhdpi/ic_launcher.png    144x144 px
- mipmap-xxxhdpi/ic_launcher.png   192x192 px

Требования к изображению:
- квадратное изображение;
- PNG, RGB или RGBA;
- прозрачный фон допускается и предпочтителен, если дизайн это предусматривает;
- без мелкого текста, который потеряется на маленьком размере;
- главный символ должен занимать примерно 70–80% площади;
- иконка должна хорошо читаться как на экране автомобиля, так и в списке приложений.

После подготовки иконки файлы нужно разместить в соответствующих папках:
app/src/main/res/mipmap-mdpi/
app/src/main/res/mipmap-hdpi/
app/src/main/res/mipmap-xhdpi/
app/src/main/res/mipmap-xxhdpi/
app/src/main/res/mipmap-xxxhdpi/

Имя файла во всех папках: ic_launcher.png

После получения готовой иконки подключим её в AndroidManifest.xml через:
android:icon="@mipmap/ic_launcher"

Сборка
Проект использует Android Gradle Plugin 9.0.1, Gradle 9.3.0 и Java 17.
Для platform signing необходимы файлы platform_binary.pk8 и platform.x509.pem в папке keys/.
Ключи в архив не включены.


Новое имя приложения
- Название проекта: EISWM
- Полное название: Evolute I-Space Welcome Manager
- applicationId: com.eiswm
- На главном экране приложения отображается «EISWM — Evolute I-Space Welcome Manager».
- В правом верхнем углу добавлена кнопка «Выход», закрывающая приложение.


ВСТРОЕННЫЕ MP3

Положите нужные MP3 в app/src/main/assets/welcome/. При первом запуске EISWM отсутствующие файлы будут скопированы в /storage/emulated/0/Notifications. Существующие файлы не перезаписываются. После успешного копирования устанавливается флаг, поэтому при последующих запусках файлы не восстанавливаются.

Важно: в архиве нет ваших MP3-файлов. Замените PUT_MP3_FILES_HERE.txt своими MP3 перед сборкой.
