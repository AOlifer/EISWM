EISWM v1.3 (versionCode 3)

Изменения EISWM v1.3 (база — протестированная v1.1)
Из v1.2:
- Переключатель приветствия: подпись «Приветствие: ВКЛ/ВЫКЛ/?» и кнопка-иконка динамика
  (ic_volume_up / ic_volume_off; при неизвестном состоянии — значок «?»).
- Состояние обновляется автоматически при изменении настройки bw_welcome_voice_switch
  в системе (ContentObserver).
Сохранено из v1.1:
- Чтение настройки с запасным путём через `settings get global`, неизвестное состояние = «?».
- Запись с проверкой результата; при неудаче — `su root settings put global`.
Исправления:
- Разделители в списках больше не исчезают после выбора файла.
- «>>» и «<<»: перед копированием показывается сводка; если файлы уже есть —
  выбор «Заменить» / «Пропустить существующие» / «Отмена». Итог: сколько скопировано,
  пропущено и сколько ошибок.
- «>»/«<» с заменой: теперь проверяется результат и показывается сообщение.
- Проверка длительности: одиночный файл длиннее 6 с — предупреждение с выбором;
  при «>>» такие файлы пропускаются. В правом списке длинные файлы помечены красным.
- Копирование через временный файл: при ошибке старый файл не портится,
  лаунчер не видит недописанный MP3.
- Копирование и чтение длительности — в фоновом потоке, интерфейс не подвисает.
- Каталог приветствия создаётся до чтения списка (раньше при его отсутствии было «недоступен»).
- Кнопки ▶/🗑 заданы в dp, а не в пикселях.
- Воспроизведение останавливается, когда приложение уходит с экрана, и перед
  удалением/заменой проигрываемого файла.
- Выделение файла сбрасывается при смене накопителя/папки и сохраняется после «Обновить».
- В манифест добавлены READ/WRITE_EXTERNAL_STORAGE (на текущей прошивке доступ даёт system uid).

Назначение
Управление MP3-файлами в каталоге приветствия:
/data/user_de/0/com.android.launcher3/files/welcome/message

Изменения EISWM v1
- Справочная информация сделана компактной горизонтальной панелью, чтобы не занимать высоту экрана.
- Верхняя кнопка «Обновить» перенесена в нижнюю панель.
- Нижняя панель разделена на две части:
  слева — «Вверх», «Память устройства», «Внешние накопители», «Обновить»;
  справа — статус воспроизведения и «Стоп».
- «Память устройства» возвращает из внешнего накопителя во внутреннюю память.
- При выборе внутренней памяти корнем навигации является только /storage/emulated/0.
- При выборе внешнего накопителя навигация ограничена корнем выбранного накопителя.
- Слева показываются каталоги и MP3-файлы.

Иконка приложения
Для Android 9 достаточно обычной PNG-иконки. Рекомендуемый комплект:
- mipmap-mdpi/ic_launcher.png       48x48 px
- mipmap-hdpi/ic_launcher.png       72x72 px
- mipmap-xhdpi/ic_launcher.png      96x96 px
- mipmap-xxhdpi/ic_launcher.png    144x144 px
- mipmap-xxxhdpi/ic_launcher.png   192x192 px

Имя файла во всех папках: ic_launcher.png
Подключена в AndroidManifest.xml через android:icon="@mipmap/ic_launcher".

Сборка
Проект использует Android Gradle Plugin 9.0.1, Gradle 9.3.0 и Java 17
(как в протестированной v1.1; обновление до AGP 9.2.1 / Gradle 9.4.1 из v1.2 не переносилось).
Для platform signing необходимы файлы platform_binary.pk8 и platform.x509.pem в папке keys/.

Новое имя приложения
- Название проекта: EISWM
- Полное название: Evolute I-Space Welcome Manager
- applicationId: com.eiswm
- В правом верхнем углу кнопка «Выход», закрывающая приложение.

ВСТРОЕННЫЕ MP3
Положите нужные MP3 в app/src/main/assets/welcome/. При первом запуске EISWM отсутствующие файлы
будут скопированы в /storage/emulated/0/Notifications. Существующие файлы не перезаписываются.
После успешного копирования устанавливается флаг, поэтому при последующих запусках файлы не восстанавливаются.
