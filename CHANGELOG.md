# Журнал изменений

Все заметные изменения проекта EISWM описываются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено]

### Добавлено

- Скрытый экран «Диагностика машины» (долгое нажатие на номер версии на стартовом экране),
  чтобы узнать, какие события машины может использовать приложение. Только чтение: в машину
  ничего не записывается.
  - «Сделать снимок машины»: все свойства, которые отдаёт сервис машины, с текущими значениями,
    ключи Settings и наличие файлов анимаций приветствия и прощания в `/system/media`.
    Значения токенов, номеров, адресов, идентификаторов и VIN в файлы не попадают.
  - «Начать запись событий»: фоновая запись в журнал изменений свойств машины, состояний
    питания и сна, броадкастов, ключей Settings и свойств системы. При включении записи сразу
    делается снимок; запись продолжается после перезагрузки и сна машины, пока её не остановить.
  - «Отметка в журнале» и «Сохранить файлы в…» (на флешку).
  - API машины берётся из библиотеки прошивки `bw.car.proxy`; без неё приложение работает
    как раньше.

### Изменено

- Внутренняя переработка кода; работа приложения не изменилась.

### Исправлено

- Экранный диктор (TalkBack) называл галочку на превью в разделе «Картинки» «Выделить все»;
  теперь он говорит «Выбрать» и имя картинки.

## [1.5.1] — 2026-09-29

### Изменено

- Обновления берутся со стандартного адреса GitHub Pages репозитория вместо своего домена:
  для своего домена GitHub не смог выпустить сертификат HTTPS, и 1.5 не видела обновлений.
  Файл `docs/CNAME` удалён. Эту версию нужно один раз поставить вручную.
- Из `docs/ANALYSIS.md` и CHANGELOG убран адрес сервера обновлений.

## [1.5] — 2026-09-29

Управление картинками приветствия, обновления с сервера, английский, немецкий и китайский языки.

### Добавлено

- Раздел «Картинки»: управление картинками приветствия лаунчера (папка `files/welcome/advice/`
  и база `welcome_db`, таблица `welcome_advice`). Сетка превью, просмотр крупно, «Сохранить копию в…»,
  удаление, отметка картинок с истёкшим сроком показа.
- Добавление картинок (PNG, JPG, WEBP, BMP) через экран выбора файлов с превью и размером;
  картинка подгоняется под 1920×720 с обрезкой по центру и сохраняется в PNG.
- Выключатель «Показывать картинки» / «Не показывать картинки»: при выключении записи
  откладываются, в базе остаётся чёрная картинка; при включении всё возвращается.
  Сводка под ним начинается со слова «Загружено».
- Копии добавленных картинок и их восстановление при запуске приложения и при старте машины
  (`BootReceiver`), если их стёрла служба загрузки лаунчера.
- «Стандартные картинки»: 16 штатных картинок лаунчера с русским текстом встроены в приложение.
  Их можно добавить по одной или все сразу на круглый год, либо включить «По временам года»:
  в каждом сезоне машина показывает одну из четырёх картинок этого сезона, сроки на следующий год
  обновляются при запуске и при старте машины. В README отмечено, что права на них у производителя.
- Выделение картинок в разделе «Картинки»: галочки на превью, «Выделить все», «Очистить» и «Удалить (N)».
- «Выделить все» и «Очистить» на экранах стандартных картинок и выбора файлов (вместо одной кнопки-переключателя).
- Стартовый экран: приложение открывается без выбранного раздела — картинка Evolute i-Space
  (для светлой темы в скруглённой карточке, для тёмной с растворяющимися краями), название, версия,
  описание, кнопки «Звуки» и «Картинки», разработчик (Telegram @oaaspb) и лицензия. Нажатие на логотип или название
  вверху возвращает на него; своя «Помощь».
- Локализация: язык интерфейса по настройкам системы, по умолчанию английский
  (`values/strings.xml`), переводы на русский (`values-ru/strings.xml`) и немецкий
  (`values-de/strings.xml`). Все надписи вынесены из кода
  и разметки в ресурсы, множественное число — через `<plurals>`, единицы и десятичный разделитель
  по языку системы. Название приложения по-английски — «Welcome Manager».
- Отказ от ответственности: файл `DISCLAIMER.md` (русский и английский), раздел в README,
  окно при первом запуске приложения (закрывается только кнопкой «Понятно») и строка
  «⚠ Неофициальное приложение, используется на свой риск. Подробнее…» на стартовом экране.
- README: везде уточнено, что приложение для Evolute I-Space первого (дорестайлингового) поколения.
- Раздел README «Коммерческое использование»: продажа и платная установка возможны только
  по отдельной коммерческой лицензии от автора, контакты Telegram @oaaspb и GitHub AOlifer.
- Инструкция пользователя `docs/INSTRUCTION.md` со скриншотами русского интерфейса
  (`docs/images/`), ссылка на неё в начале README.
- Обновления с сервера: «Проверить обновления» рядом с версией на стартовом экране и проверка
  при запуске не чаще раза в сутки. Файл на сервере обновлений (JSON: номер
  и название версии, ссылка на APK, размер, SHA-256, описание изменений на трёх языках);
  если версия новее, «Доступна версия N. Подробнее…» открывает описание и «Скачать и установить».
  APK проверяется и ставится без системного установщика, после установки приложение открывается
  снова (`Updater.java`, разрешения `INTERNET` и `INSTALL_PACKAGES`). Вариант `emulator` только
  скачивает и проверяет обновление. Формат описан в `docs/ANALYSIS.md`, раздел «Обновления».
- Сервер обновлений на GitHub Pages: JSON последней версии в `docs/updates/latest`, сайт
  публикуется из ветки `master`, APK
  прикладывается к выпуску на GitHub. Порядок публикации описан в `docs/ANALYSIS.md`, раздел «Обновления».

### Изменено

- Инструкция: отмечено, что на эмуляторе в разделе «Звуки» вместо состояния звукового
  приветствия написано «Не удалось узнать, включён ли звук».
- Китайская локализация (`values-zh/strings.xml`, упрощённые иероглифы; название — «迎宾管理器»,
  в лаунчере — «迎宾»). В описании обновления на сервере можно указать и `zh`.
- README, инструкция и `docs/ANALYSIS.md`: приложение проверено только на Evolute I-Space
  2024 года выпуска липецкой сборки; добавлено предположение о возможной совместимости
  с базовой моделью Dongfeng Fengon E5 (Landian E5, экспортная DFSK E5) и другими адаптациями
  с тем же головным устройством.
- Строка «⚠ Неофициальное приложение…» убрана со стартового экрана и перенесена в «Помощь»
  стартового экрана вместе с кнопкой «Отказ от ответственности», которая открывает полный текст.
- Вёрстка подстраивается под окно уже экрана машины (например, когда при запуске из лаунчера
  остаётся видна его боковая панель): картинка на стартовом экране уменьшается, текст стартового
  экрана и боковые панели разделов и стандартных картинок прокручиваются, боковые панели в узком
  окне уже (300 dp вместо 360), кнопки на стартовом экране растягиваются по ширине колонки,
  кнопки-ссылки («Выделить все», «Очистить») не переносятся на вторую строку, подпись под
  картинкой обрезается многоточием, а «Удалить (N)» в разделе «Картинки» не занимает место,
  пока ничего не выделено.
- README сокращён до краткого описания, списка возможностей, установки и лицензии. Устройство
  проекта (механизм приветствия в лаунчере, интерфейс, обновления, сборка, эмулятор, подпись,
  иконка, ветки, сторонние материалы) перенесено в `docs/ANALYSIS.md`. Из документации убраны
  адрес сервера обновлений, сведения о сертификате и имена файлов ключа.
- `versionCode` 7 (промежуточные сборки 1.5 до выпуска были с `versionCode` 5 и 6).
- Приложение открывается со стартового экрана, а не с последнего открытого раздела.
- Короткое имя под значком в лаунчере: «Приветствие» / «Welcome» / «Begrüßung» (`app_label`);
  полное название остаётся в заголовке приложения.
- Первая установка: если в базе лаунчера нет ни одной записи и в папке картинок нет файлов,
  при первом запуске ставится стандартная картинка `bw_welcome_summer2.png` на круглый год.
- Раздел «Звуки»: убрана подпись «Звуковое приветствие», переключатель подписан
  «Воспроизводить звуки» / «Не воспроизводить звуки», сводка начинается со слова «Загружено».
- Лицензия сменена с MIT на PolyForm Noncommercial 1.0.0: доработки для себя разрешены,
  продажа и коммерческое использование запрещены, при передаче копий обязательна ссылка на автора
  (строка `Required Notice` в LICENSE). Версии до 1.4 включительно остаются под MIT.

## [1.4] — 2026-09-28

Новый интерфейс под широкий экран машины.

### Добавлено

- Файл `CHANGELOG.md` с историей изменений (перенесена из README).
- Лицензия MIT (файл `LICENSE`) и раздел «Лицензия» в README.
- Схема веток: `develop` для разработки, `master` для релизов (раздел «Ветки» в README).
- Вариант сборки `emulator` для проверки интерфейса в эмуляторе Android Studio: без system uid,
  с debug-подписью и `applicationId` `com.eiswm.emulator` (раздел «Эмулятор» в README).
- Колонка разделов слева: «Звуки» и «Картинки» (место под будущее
  управление картинками, пока в разработке). Новые разделы добавляются в `MainActivity.setupSections()`.
- Экран выбора файлов в три колонки: накопители, папка с путём (каждая часть нажимается),
  список выбранного с кнопкой ✕. Галочки, прослушивание, проверка длительности,
  «Выбрать все в папке» и «Добавить N звуков». Экран общий и настраивается через `Intent`,
  чтобы потом подключить к нему картинки.
- «Сохранить копию в…» в меню ⋮ у звука: копия в выбранную папку памяти или флешки.
- Тёмная тема и кнопка «Тема» внизу колонки разделов: авто (по ночному режиму системы),
  светлая, тёмная.
- «Помощь» своя для каждого раздела.
- Если звуковое приветствие выключено, под переключателем написано, что машина не будет
  проигрывать звук при включении автомобиля.
- При выходе во время копирования приложение спрашивает «Дождаться» или «Выйти сейчас».
- При запуске удаляются временные файлы `.имя.tmp`, оставшиеся от прерванного копирования.
- Адаптивная иконка для Android 8+: лаунчер обрезает её по своей форме, а не вписывает
  уменьшенную картинку в белый круг.

### Изменено

- `README.txt` заменён на `README.md` с разметкой Markdown.
- APK для машины теперь собирается как вариант `car`: `assembleCarDebug`,
  результат в `app/build/outputs/apk/car/debug/app-car-debug.apk`.
- Новый интерфейс под широкий экран вместо двух панелей со стрелками `>`, `>>`, `<`, `<<`:
  по центру звуки, которые стоят в машине, с крупными кнопками ▶ и ⋮, полоской прогресса и
  цветной меткой длительности; справа панель с переключателем приветствия, подсказкой и кнопкой
  «Добавить звуки»; звуки добавляются через отдельный экран выбора файлов.
- Звуки длиннее 6 секунд больше не запрещены: машина играет их и обрывает на 6-й секунде.
  Они отмечены жёлтой меткой «оборвётся на 6 с», перед добавлением приложение предупреждает.
- Заголовок по-русски: логотип и название «Менеджер приветствия» (`app_name`). В тёмной теме
  логотип светится на плашке своего фонового цвета, в светлой — отдельный вариант на фоне панели.
- Колонка разделов стала узкой (значок над подписью); значки разделов, накопителей и папок
  заменены с эмодзи на векторные Material Icons.
- Переключатель приветствия стал обычным переключателем с подписью; справка перенесена
  в диалог «Помощь».
- В помощи уточнено: звук приветствия играет при включении автомобиля.
- Длительность и размер показываются с запятой («3,9 с») независимо от языка системы.
- В варианте `emulator` звуки приветствия хранятся в `/storage/emulated/0/EISWM/welcome`,
  чтобы на эмуляторе работали добавление и удаление.

### Исправлено

- Системная кнопка «Назад» на главном экране закрывает приложение так же, как «Выход»,
  и убирает его из недавних.

## [1.3]

База — протестированная v1.1.

### Добавлено (из v1.2)

- Переключатель приветствия: подпись «Приветствие: ВКЛ/ВЫКЛ/?» и кнопка-иконка динамика
  (`ic_volume_up` / `ic_volume_off`; при неизвестном состоянии — значок «?»).
- Состояние обновляется автоматически при изменении настройки `bw_welcome_voice_switch`
  в системе (`ContentObserver`).

### Сохранено из v1.1

- Чтение настройки с запасным путём через `settings get global`, неизвестное состояние = «?».
- Запись с проверкой результата; при неудаче — `su root settings put global`.

### Исправлено

- Разделители в списках больше не исчезают после выбора файла.
- `>>` и `<<`: перед копированием показывается сводка; если файлы уже есть —
  выбор «Заменить» / «Пропустить существующие» / «Отмена». Итог: сколько скопировано,
  пропущено и сколько ошибок.
- `>` / `<` с заменой: теперь проверяется результат и показывается сообщение.
- Проверка длительности: одиночный файл длиннее 6 с — предупреждение с выбором;
  при `>>` такие файлы пропускаются. В правом списке длинные файлы помечены красным.
- Копирование через временный файл: при ошибке старый файл не портится,
  лаунчер не видит недописанный MP3.
- Копирование и чтение длительности — в фоновом потоке, интерфейс не подвисает.
- Каталог приветствия создаётся до чтения списка (раньше при его отсутствии было «недоступен»).
- Кнопки ▶/🗑 заданы в dp, а не в пикселях.
- Воспроизведение останавливается, когда приложение уходит с экрана, и перед
  удалением/заменой проигрываемого файла.
- Выделение файла сбрасывается при смене накопителя/папки и сохраняется после «Обновить».
- В манифест добавлены `READ/WRITE_EXTERNAL_STORAGE` (на текущей прошивке доступ даёт system uid).

### Изменено

- Справочная информация сделана компактной горизонтальной панелью, чтобы не занимать высоту экрана.
- Верхняя кнопка «Обновить» перенесена в нижнюю панель.

  справа — статус воспроизведения и «Стоп».

- При выборе внутренней памяти корнем навигации является только `/storage/emulated/0`.
- При выборе внешнего накопителя навигация ограничена корнем выбранного накопителя.
- Слева показываются каталоги и MP3-файлы.
- Новое имя приложения: EISWM, кнопка «Выход» в правом верхнем углу.
